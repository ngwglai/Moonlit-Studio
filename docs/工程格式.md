# 工程格式与开发说明

## 架构

程序分为五层，生产代码不依赖第三方 npm 包：

| 文件 | 职责 |
|---|---|
| `src/core.js` | 项目格式、检查器、变量与条件、确定性剧情状态机、存档和回退 |
| `src/runtime.js` | DOM 播放器、画面、音频、计时器、历史、存档、画廊 |
| `src/storage.js` | IndexedDB 项目和恢复快照，串行写入队列 |
| `src/editor.js` | 编辑工作台、属性、导入、场景流程、导出 |
| `src/runtime.css` / `src/editor.css` | 播放器与编辑器样式 |

`core.js` 可以直接由 Node.js `require`，因此不启动浏览器也可验证两条剧情路径。`runtime.js` 和 `editor.js` 使用浏览器 DOM。`build.py` 把源文件、导出所需运行器源码和样式内嵌进一个 HTML。

编辑器的 `window.GAL_BUNDLE` 包含纯文本形式的运行器源文件和样式，用于导出独立游戏。它不使用 `eval` 执行用户输入，也不接受项目中的任意 JavaScript 指令。

导出游戏使用 `application/json` 脚本块存放项目数据，所有 `<` 被转义为 `\u003c`，避免台词里的 `</script>` 中断数据块。文本输出采用 HTML 转义或 `textContent`。只接受支持的图片、音频和视频 Data URL，不接受 SVG/HTML 或任意网络资源 URL。

## 顶层数据

```json
{
  "schemaVersion": 1,
  "id": "project_xxx",
  "title": "我的作品",
  "author": "作者",
  "description": "简介",
  "startScene": "scene_start",
  "settings": {
    "accent": "#d3ae70",
    "textSpeed": 32,
    "autoDelay": 1800,
    "fontSize": 24,
    "aspect": "16/9",
    "skipUnread": false
  },
  "variables": [{"name":"trust","type":"number","value":0}],
  "characters": [{"id":"hero","name":"主角","color":"#91b8c7","asset":""}],
  "assets": [],
  "scenes": [],
  "updatedAt": 0
}
```

ID 使用字母、数字、下划线或短横线，最长 100 字符。名称与台词可使用 Unicode。变量名允许中文字母、英文字母、数字和下划线，开头不能是数字，不允许 `__proto__`、`constructor`、`prototype`。

## 场景与指令

场景为 `{id, name, notes, next, nodes}`。`next` 为空表示场景自然结束后不继续。指令都包含唯一 `id` 与 `type`。

| type | 主要字段 |
|---|---|
| dialogue | character、text、voice |
| narration | text |
| background | asset、color、transition: fade/none |
| show | character、asset、position、scale、opacity、flip |
| hide | character |
| choice | text、options: [{text,target,condition}] |
| set | variable、op: =/+=/-=/*=、value |
| branch | condition、yes、no |
| jump | target |
| music | asset、volume、loop |
| sound | asset、volume |
| wait | duration，毫秒 |
| effect | effect: fade/shake/flash/darken、duration |
| video | asset |
| end | title、text |

条件格式：`{"variable":"trust","op":">=","value":2}`。选项条件为 null 或未选择变量时视为无条件。可用比较运算符 `== != > >= < <=`，数值按数字处理，文本按字符串处理。

素材格式：`{id,name,mime,size,data,width?,height?,gallery?}`。data 为 Base64 Data URL。width/height 仅图片需要。gallery 为 true 的图片在背景显示时解锁。

## 运行器接口

```js
const p = GalCore.normalize(jsonData);
const issues = GalCore.validate(p);
const engine = new GalCore.Engine(p);
engine.advance();      // 运行到下一条对话、选项、等待、视频或结局
engine.choose(0);      // 选择当前可见选项中的第一个
engine.rollback();    // 恢复上一个暂停点
const save = engine.save();
engine.load(save);
```

Engine 的 `state` 包含场景、游标、变量、背景、角色、当前音乐、对话、选项和结局。`events` 是本次推进产生的非持久事件，例如音效、画面效果、等待、视频、CG 解锁。播放器消费事件并处理音频或计时器。

回退快照记录的是推进前的暂停状态，因而回退越过选项时会一起恢复选择前变量。选择发生时单独创建快照，防止只恢复文字而保留路线加分。

Core 的项目克隆对素材元数据做浅复制、共享不可变字符串，避免每次打字撤销都重新序列化巨大 Base64 文件。保存到 IndexedDB 和导出文件时仍会序列化真实素材。

## 保存格式

玩家存档包含 format、version、projectId、fingerprint、time、snapshot。

fingerprint 为当前场景、变量、角色、起点和素材 ID 列表的确定性哈希，用于避免错位读取，不是密码学签名。素材数据本身不参与哈希，允许同 ID 素材更新。它不提供存档防修改、防作弊或版权保护。

浏览器项目数据库：`moonlit-studio-v1`。对象存储为 `projects` 与 `backups`。游戏进度采用 `moonlit.game.<项目ID>.*` localStorage 键。

对大型生产环境，应进一步加入分资源磁盘格式、持久存储配额管理、多窗口冲突检测、完整 schema 校验和更多浏览器实机回归。

## 构建与测试

```bash
python build.py
node --test tests/core.test.cjs
npm install
npm run test:ui
```

构建输出 `dist/Moonlit-Studio.html`、`dist/Rain-Before-Dawn.html`、`dist/Diagnostics.html`。`examples/` 中的示例工程是发行示例的权威数据，修改它再运行构建会同步更新示例成品。

测试依赖不属于生产代码。`linkedom` 提供 DOM 模拟，`fake-indexeddb` 模拟数据库事务；它们不测试 CSS 布局、真实音视频解码或浏览器权限。`Diagnostics.html` 用于目标电脑的真实功能自检。
