# Moonlit Studio 使用手册

## 一、先打开示例，跑完整流程

打开编辑器后，自带短篇《雨停之前》。它有六个场景：开场选择“接过信”会走信件路线并增加 2 点信任；选择“一起离开”会走雨伞路线并增加 1 点信任；两个路线汇入公共场景，再由 `trust >= 2` 决定结局。

可以先点击“试玩”从标题开始。也可以选择一个场景，点击“从本幕试玩”。后者以变量初始值开始，不能自动获得前面路线积累的好感度。检查完整剧情应使用从头试玩。

示例没有角色立绘、背景图片和音乐，使用纯色氛围背景。你可以替换为自己的素材，不需要先删除示例中的文字和分支。

## 二、界面的三个工作区域

左边是场景列表，中间是工作区，右边是属性编辑器。顶部提供备份、导出和试玩。

“剧情编辑”展示选中指令对应的画面与本幕指令列表。选择指令后在右边编辑。对话与旁白的文字输入会实时更新画面，其他属性在确认输入或失去焦点后更新。

“分支流程”展示实际的场景连接，包含默认后继、选项跳转、条件跳转和直接跳转。复杂环路可能出现连线重叠，此时点击场景卡片检查指令。

“素材库”“角色”“变量”“作品设置”分别管理共用资源。选中素材或角色后，右侧显示对应属性。

## 三、建立一个新作品

点击顶部作品名，选择“空白项目”。到“作品设置”填写作品标题、作者和简介，选择画面比例、主题色与默认阅读速度。

第一个场景默认是起点，可以修改。新建场景不会自动连接，连接方式有三种：在场景设置指定默认后继；添加“跳转场景”；使用“选项分支”或“条件判断”。

每幕执行到末尾时，若设置了默认后继就进入下一幕，否则显示结束。已经执行选项、条件判断或直接跳转后，不会再执行本幕后续指令。

场景删除会保留其他场景的失效引用，让检查器明确提示修复位置，不会偷偷改变故事路线。复制场景会生成新的指令 ID，并把原场景指向自身的跳转映射到副本自身。

## 四、导入图片、音乐、配音和视频

进入素材库，点击“导入素材”，或者把文件拖进素材区域。支持：

| 类型 | 支持格式与建议 |
|---|---|
| 背景 / CG | PNG、JPEG、WebP、GIF、AVIF；宽屏建议 1920×1080 |
| 立绘 | 透明 PNG / WebP，底部贴近角色脚底，避免不必要的留白 |
| 音乐 / 音效 / 配音 | MP3、WAV、OGG、M4A 等浏览器可播放音频 |
| 视频 | MP4、WebM、OGG；建议先在目标浏览器试播 |

单个素材最多 40 MB。导入时按文件实际内容去重，相同内容不会重复加入。文件只在本地读取。素材被打包进工程文件和导出的游戏，不需要保留原文件路径。

选中素材可以重命名、查看引用次数、预览，或用“替换文件（保留引用）”更新它。替换必须是同类文件，例如图片替换图片。这样已经编排好的背景、角色和配音指令无需重做。

删除被引用素材后，相关指令会产生检查错误。可以撤销删除，或重新指定素材。

## 五、角色与画面演出

在角色页建立角色，填写姓名、姓名颜色和默认立绘。台词角色不会自动出现在画面上，要先添加“显示立绘”指令。

同一个角色再次执行显示指令时会替换原有立绘，可用于表情和服装切换；不同角色会同时保留。“隐藏立绘”只移除指定角色。

显示指令的水平位置为相对画面宽度百分比：0 是左边，50 是中央，100 是右边。高度以画面可用立绘区域为基准。可以调整透明度、镜像翻转，也可以选中该显示指令后直接拖动预览中的角色来修改横向位置。

背景指令支持图片或纯色，并可选择淡入或立即切换。立绘和背景默认跨场景保留，直到新的指令修改。编辑器预览只重建当前幕的线性指令，不会推导所有上游分支；跨幕继承的实际结果请用完整试玩确认。

对话可以单独指定一条配音。“背景音乐”保持播放并可循环；不选择文件时表示停止音乐。“音效”是一次性播放。“播放视频”会暂停剧情，结束后继续，玩家也可跳过。

“等待”暂停指定毫秒。“画面效果”支持淡入、震动、闪白和闪黑；若希望效果结束后再继续其他指令，应在后面加相应时长的等待。效果不是独立动画时间轴。

## 六、台词编辑和批量导入

每条对话支持换行。姓名、旁白和台词中的 `{{变量名}}` 会替换为当前变量值，例如 `你们的信任变成了 {{trust}}。`。

批量导入把每个非空行当作一条指令。使用全角或半角冒号分隔姓名和台词：

```text
【场景：王宫清晨】
晨光落在书页上。
奈莉茜：今天的会议推迟半小时。
丽薇雅：那您至少先把早饭吃完。
【场景：走廊】
脚步声在长廊中响起。
```

“旁白：文字”会作为旁白。其他带短名称和冒号的行会识别为角色台词；文本本身有冒号但不表示角色时，可以导入后改成旁白。空白行忽略。TXT 请使用 UTF-8，最多 5 MB，一次最多 20000 行。

有分幕标记时会新建场景并顺序连接，但不会擅自将原项目场景连接进新内容。需要在流程中手动接入。没有分幕标记时，指令插入到当前选中位置之后。导入不会覆盖既有内容，可以撤销。

全文查找替换作用于对话、旁白、选择提示、选项文字、结局文字和标题。它不改角色名、场景名或变量名。变量名称要使用变量页的专用重命名功能。

## 七、变量、好感度与分支

变量有三种类型：数字、文本、布尔。初始值在新游戏开始时生效。

| 需求 | 设置方法 |
|---|---|
| 增加好感度 | 数字变量 `trust`，赋值 `+= 1` |
| 设置路线 | 文本变量 `route`，赋值 `= letter` |
| 获取物品 | 布尔变量 `has_key`，赋值 `= true` |
| 达成好结局 | 条件 `trust >= 3`，分别指定成立/不成立场景 |
| 有钥匙才显示选项 | 选项出现条件 `has_key == true` |
| 动态显示名字 | 文本变量 `player`，角色姓名填写 `{{player}}` |

比较会按变量当前类型处理输入；数字变量比较数值，文本变量比较文本，布尔变量使用 true / false。数字支持 `=`、`+=`、`-=`、`*=`；文本和布尔只支持 `=`。

建议每个选择至少保留一个无条件选项，否则可能出现所有选项都不满足的情况。运行时会明确报错，不会卡在空白选择界面。

变量不支持任意 JavaScript 表达式或函数执行，条件采用可视化字段配置。复杂逻辑可以组合多个赋值和条件指令。

## 八、预览、检查和调试

“检查项目”会验证错误引用、重复 ID、缺失跳转、非法变量、赋值类型、素材类型、无可选项风险和不可达场景。点击检查结果会跳到对应位置。

阻止运行的错误需要先修复，提醒可以保留。例如没有图片的角色可以只有台词。检查器不是剧情逻辑证明器：路线是否合理、条件是否符合创作意图，仍需分别试玩。

运行器一次推进最多执行 2000 条不暂停的指令，检测到可能的无限循环会中断并显示场景位置。文字回退最多保留 150 个运行快照，阅读历史最多保留 500 条。

当前版本没有断点面板或运行时变量编辑器。调试变量可以暂时把 `{{变量名}}` 写进旁白，也可从目标场景使用初始值试玩。

## 九、保存、快照与作品标识

自动保存：编辑停顿后约 700 毫秒写入浏览器 IndexedDB。顶部会显示成功或失败状态。失败时仍可下载项目文件。

手动快照：在作品设置中创建，最多保留最近 8 个。恢复前会先保存当前版本；恢复动作也可撤销。快照仍在本机浏览器里，不是外部备份。

项目文件：`Ctrl+S` 或“备份项目”下载包含素材的 `.galproject.json`。建议每天、重要分支改动前、移动编辑器前各保留一个版本。

导入工程默认保留原作品 ID。若浏览器已有相同 ID 的项目，可以选择备份后替换，或作为新 ID 的独立副本打开。独立副本不共享原作品的玩家存档。

请避免用多个编辑器窗口同时修改同一个项目。此版本没有多窗口冲突合并或协作锁。

## 十、玩家存档与阅读控制

游戏存档位在浏览器 localStorage；不同作品 ID 隔离保存。自动存档在普通台词处更新，手动存档可保留选择前后的状态。存档中包括场景游标、变量、背景、角色、音乐和阅读历史。

存档文件可以导出并在另一台电脑导入。场景、指令、变量或角色定义改变后，内容指纹不同的旧存档会被拒绝，避免错位读取；只替换同 ID 素材不会改变剧情指纹。

播放器快捷键：空格、回车或右方向键继续，左方向键回退，H 隐藏/显示文字，Esc 打开或关闭菜单。对话隐藏后，点击画面先恢复文字，不跳过当前句。选项支持 Tab 和 Enter 操作。

自动阅读等待当前配音结束后再推进。默认快进只跳过曾经出现过的台词；作品设置可开放未读快进。文字速度设为 0 即完整瞬间显示。

选中图片素材并勾选“加入回忆画廊”，玩家在背景指令中看到它之后会解锁。结局通过“结局”指令到达时解锁。单纯在编辑器预览不解锁玩家收集。

## 十一、发布与离线运行

导出的独立 HTML 包含剧情、图片、声音、视频、运行引擎和样式。可以直接发送这个文件；电脑端用浏览器打开即可。可将它放到普通静态网站托管，但本工具不会自动发布或替你上传内容。

移动系统有时会把下载的 HTML 当作预览附件而非可执行网页；移动发布更适合通过 HTTPS 静态托管。未经过 iOS/Android 实机测试。

HTML 成品中的剧本和素材可被有技术能力的玩家提取；不提供资源加密或 DRM。若需要商业发行、EXE/APK、分包、补丁更新或资源流式加载，可以在开源代码基础上继续扩展。

## 十二、遇到问题

- **打开后没有保存状态**：运行 `Diagnostics.html`，换用常规模式的 Chrome / Edge，并下载项目备份。
- **没有声音**：先点击“开始故事”，确认游戏总音量及系统音量；在素材库直接预览音频，检查浏览器是否支持编码。
- **人物太大或不在画面里**：检查透明图片留白、显示指令的高度与水平位置。
- **新场景到不了**：检查起点、场景默认后继，以及选项或条件的目标。
- **选项不显示**：确认变量初始值、前面的赋值是否执行、条件类型是否匹配。
- **读不了旧存档**：工程结构可能已经修改。使用旧版本游戏或从新版本重新开始。
- **导出文件过大**：压缩图片与音频，删除未引用素材。这里没有自动有损压缩，避免无提示降低素材质量。
- **要升级编辑器**：先导出项目备份，再换新版 HTML，随后导入项目。不要指望更换文件后浏览器存储自动迁移。
