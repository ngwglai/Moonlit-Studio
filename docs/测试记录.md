## 尚未完成的验收

当前可用的远程浏览器安全策略禁止访问工作环境的 localhost 与 file:// 文件，因此没有完成真实浏览器的视觉验收。这一限制没有通过其他浏览器或绕过路径规避。

DOM 测试使用 linkedom，数据库使用 fake-indexeddb，Audio / 视频播放使用测试替身。因此以下内容不能据此声称已实测通过：

- Chrome / Edge 的真实 CSS 布局与 100% / 200% 缩放效果；
- 实际鼠标拖动立绘和文件拖放；
- 真正音频解码、音量输出、视频播放和自动播放策略；
- Windows、macOS、iOS、Android 的系统级文件下载行为；
- 真机持久存储配额和浏览器隐私设置；
- 100 MB 以上工程或数万条指令下的长时间性能。

`Diagnostics.html` 提供可在目标电脑直接运行的 11 项检查及提示音测试。它不会读取或改写现有项目，只会创建并删除自己的临时测试存储。

## 建议的首次验收路径

1. 解压，打开 Diagnostics，确认数据库与音频支持。
2. 打开编辑器，从头试玩示例的两个选择，确认两个结局。
3. 随意修改一句台词，撤销、重做，刷新后确认自动保存。
4. 导入一张背景、一张透明立绘、一条配音和一段 BGM，安排在示例开场。
5. 试玩，检查立绘位置和音量，保存一个存档后回退再读取。
6. 导出项目与独立 HTML，关闭编辑器，打开成品游玩。
7. 用项目文件重新打开工程，确认文字和素材仍在。

该清单是待做的真实环境验收，不是本次已经执行的测试。
