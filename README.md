# Moonlit Studio 1.0

一个离线优先、全中文的 Galgame 编辑器与独立运行引擎。没有运行时第三方依赖，不要求账号、API Key、Python 或 Node.js。

## 开始使用

1. 解压发行包到一个固定文件夹。
2. 用 Chrome 或 Edge 打开 `Moonlit-Studio.html`。第一次启动自带“雨停之前”示例。
3. 如果不确定环境是否兼容，打开 `Diagnostics.html` 运行本机自检。
4. “作品名”菜单可以新建空白项目、打开项目文件、切换本机项目或载入示例副本。
5. 使用“备份项目”下载带有所有素材的 `.galproject.json`。使用“导出游戏”下载独立可玩的 HTML。

Windows 可双击 `Start-Windows.bat` 启动；它只是调用默认浏览器打开本地 HTML，不安装软件。

**建议使用固定位置的编辑器文件、固定浏览器，并定期下载项目备份。** 浏览器的自动保存不是磁盘工程文件，清理浏览器数据、隐私模式、切换浏览器或移动文件可能让它不可用。项目数据从不自动上传。

## 已实现的创作流程

- 多项目本地管理、自动保存、8 个手动恢复快照、可移植项目文件。
- 场景增删复制、重排、创作备注、指定起点及默认后继。
- 15 种剧情指令：对话、旁白、背景、显示/隐藏立绘、选项、赋值、条件、跳转、音乐、音效、等待、效果、视频、结局。
- 当前幕实时画面预览；立绘位置、大小、透明度、翻转及直接拖动水平位置。
- 指令拖动排序、多选、60 步撤销重做、跨幕复制粘贴与全文查找替换。
- TXT 批量导入，自动识别“角色名：台词”，支持【场景：名称】分幕。
- 图片、音频与视频导入，内容去重、素材引用计数、保持引用的文件替换。
- 角色姓名颜色、默认立绘、各条显示指令覆盖表情与服装。
- 数字、文本、布尔变量；赋值、加减乘、条件分支、选项出现条件、文本插值。
- 从真实跳转关系生成分支流程图，点击跳回场景。
- 项目检查：引用、目标、类型、重复 ID、条件、无出口选项、不可达场景等。
- 独立 HTML 导出、剧本 TXT 导出、项目 JSON 导入导出。

## 玩家功能

- 标题菜单、打字机文本、即时显示、自动阅读、已读快进。
- 台词配音、BGM、音效、视频、淡入、震动、闪白与闪黑。
- 阅读历史、返回上一条（变量、立绘、背景和分支同时恢复）。
- 12 个存档位、自动存档、存档文件导入导出。
- 设置文字速度、自动间隔、总音量和语音音量。
- CG 画廊解锁与结局收集。
- 16:9 / 4:3、窗口尺寸自适应、键盘操作。

## 开发

改完 `src/` 后执行 `python build.py`，输出在 `dist/`。构建使用 Python 3 标准库，无需联网安装任何东西。运行程序本身不需要 Python。

运行核心测试：`node --test tests/core.test.cjs`（Node 20+）。

运行 DOM 集成测试需要开发依赖 `linkedom`、`fake-indexeddb`：`npm install`，随后 `npm run test:ui`。这些依赖只用于测试，不会打包进编辑器。测试模拟 DOM 和 IndexedDB，不等同于真实浏览器渲染与媒体解码测试。

## 当前范围与限制

这是一套可编辑、可导出、带完整源码的 1.0 引擎，不是 Ren'Py / Unity 的全部功能替代。当前不包含 Live2D/Spine、骨骼动画、EXE/APK 安装包生成、多人协作、在线 AI、复杂动画时间轴与富文本标签。角色采用图片立绘；文件导出格式为 HTML。

单个素材上限 40 MB；导入项目上限 300 MB。建议小中型作品控制在 100 MB 左右，音频优先 MP3/OGG，图片按实际显示分辨率压缩。全部素材内嵌时，Base64 会使文件体积增大约三分之一；超大体积商业作品更适合拆分资源或后续扩展目录导出。

支持的设计目标是桌面 Chrome / Edge。移动端做了布局适配，但没有实机验收。播放器能否解码某个音视频由浏览器和编码格式决定，扩展名正确不代表编码一定受支持。

MIT 许可适用于本项目程序和原创示例文本；用户导入的素材权利由素材自身决定。
